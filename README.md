# DS Tracker

**A small, private, offline exam planner for students.** Log your upcoming exams (DS), see what is coming
first, and track whether you have finished revising for each one.

> 🤖 **Written entirely by AI.** Every line of code, documentation and design in this repository was
> generated by an AI assistant (Claude, by Anthropic), directed by [VivirLaTruffe](https://github.com/VivirLaTruffe).
> No line was written by hand. Read it, test it and trust it accordingly.

## What it does

The interface is in French. For each exam you record:

| Field | Options |
|---|---|
| Subject | Fully editable list with colours (pre-filled with a typical engineering-school set) |
| Type | QCM, DST (sur table), En ligne, Oral, TP noté, Sur machine, Projet / rapport, Autre |
| Date & start time | — |
| Duration | Minutes, with quick presets (30 min → 4 h) |
| Importance | Faible, Normale, Élevée, Critique |
| Revision | "Finished revising" checkbox, one click from the list |
| Notes | Free text (allowed documents, chapters, room…) |

Two views:

- **List** — exams grouped by *Today / This week / Next week / Later / Past*, with a countdown
  (`J-3`), and a warning colour when an exam is close and revision is not finished (sooner for
  High/Critical exams).
- **Calendar** — month grid, one coloured chip per exam (✓ once revised); click a day to add an exam.

Plus filters (subject, type, importance, revision status) and a summary of what is left to revise.

The header switches between two pages: **DS Tracker** (exams) and **TD Tracker** (see below).

## TD Tracker: what to prepare before class

The second page reads your timetable and tells you which **TD** (tutorial session) to prepare before
you sit in it — the day before and the day itself (configurable up to 3 days ahead).

1. In your school's timetable (built and tested for **ADE**), export a period as **iCalendar** and
   save the `.ics` file. Any calendar that exports `.ics` works.
2. Click **Importer mon planning (.ics)**. The file is read in your browser; nothing is uploaded.
3. Sessions whose title contains "TD" are listed under **À préparer maintenant** with a
   "prepared" checkbox. Course names (`Mathématiques`, `Electrostatique`…) can be linked to your
   own subjects in **Matières des cours**; names that resemble a subject are matched automatically.

Re-import when your timetable changes: the days covered by the new file are replaced, the rest is
kept, and your "prepared" ticks are preserved. The app cannot log in to ADE for you (it is a static
page with no server), so importing is a manual step.

## Your data stays yours

There is **no server, no account, no tracking**. The app is plain HTML/CSS/JS.

Where your exams live is *your* choice:

1. **Linked file (Chrome, Edge, Opera…)** — click **Open / create data file** and pick a `.json`
   anywhere you like (a private git repo, a synced folder, a USB stick). The app reads it and saves
   to it automatically on every change. Nothing else is uploaded anywhere.
2. **Import / Export (any browser)** — Firefox and Safari don't allow writing to a chosen file, so use
   **Export** to download your data and **Import** to load it back.
3. In every case a copy is also kept in your browser's local storage as a safety net.

Your imported timetable (titles, times, rooms — no teacher names) is stored in that same file, so keep it
private. Tip for using it on several computers: keep the JSON in a private git repository and
`git pull` / `git push` it like any other file.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

then visit <http://localhost:8000>. It can also be hosted as-is on GitHub Pages.
